7. Admin event management

Sign in as admin. Create a record, switch to a student and search for it. Load the record before editing; stale versions return 409. Prices are in paise (100 paise = ₹1). All demo timestamps include an explicit UTC offset.

8. Room availability

Scheduled availability is not proof of physical vacancy. A room needs opening hours, complete timetable coverage and no overlapping booking or closure. Unknown information stays unknown.

9. Admin room scheduling

Admin only. Choose a resource and use its JSON template to create a record. Load a record before editing; updates and archives use the loaded version. Dates need UTC offsets. Weekly bookings require an inclusive recurrence_until local date.

Rooms: opening_hours=null means unknown; [] means explicitly closed. Coverage completeness needs both bounds. Exceptions refer to the original campus-local occurrence date and use cancel or replace. Closures may overlap bookings and still block availability. Reference data supplies building/facility IDs.

10. Faculty office hours

Resolve a name or alias before choosing a faculty ID. Ambiguous names return candidates. Published office hours and dated exceptions are the only basis for meeting slots.

11. Admin faculty publication

Admin only. Create a faculty record, then aliases, weekly office-hour rules and dated exceptions. Complete publication coverage is an explicit statement over local dates; missing publication is never treated as no slots.

Weekdays: Monday=0 to Sunday=6. Effective/coverage dates are inclusive. An exception targets an original local occurrence date; replace needs concrete replacement_start/end. Alias changes increment faculty version; exception changes increment office-hour-rule version. Reload parent records before editing.

12. Private history and saved records

Student only. Open history to restore a conversation and its active clarification. Deleting a conversation permanently removes its questions, answers and state; saved records stay independent. Saved records show current published data and changed/cancelled/archived status.
